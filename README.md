# FlowDesk — Enterprise Dashboard

A responsive business dashboard prototype for teams that need a simple overview of projects, tasks, team members, customers, and reports.

## Live Demo

**https://anmt3878-rgb.github.io/FlowDesk-Enterprise-Dashboard/**

## Features

- **Dashboard overview** — at-a-glance project, task, team, and customer counts
- **Project tracking** — owners, deadlines, progress, and status
- **Task management** — assignees, due dates, priority, and completion status
- **Team directory** — team members, contact emails, and roles
- **Customer list** — company, contact person, and customer type
- **Reports** — export project, task, and customer records to CSV
- **Workspace settings** — workspace name, owner, contact email, and currency
- **Responsive layout** — desktop, tablet, and mobile-friendly navigation
- **Browser persistence** — demo changes are saved in localStorage

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage
- GitHub Pages

## Run locally

Download or clone this repository and open `index.html` in a modern browser. No build step is required.

## Important demo limitation

This is a **front-end portfolio prototype**. Records and settings are stored only in the current browser using localStorage. It does not currently include authentication, a shared database, server-side permissions, or multi-user synchronization. Do not enter real customer information or sensitive business data. A production version would need a secure backend and database.

## Project purpose

FlowDesk demonstrates a clean business-dashboard interface and common workflow interactions for project tracking, task management, customer records, team directories, and CSV reporting.
